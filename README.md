Eight Arms, One Agent: a single emoji that stands for an autonomous AI agent. The octopus does many things at once, fast and nonstop, eight arms on eight threads of work, playful without being the obvious robot or smiley half the field will send. The program writes that one glyph to /output/entry.txt.

## Run it

```sh
python3 main.py
```
